# URL Bot — установка и управление через SSH

Версия 1.3.0 включает рассылки: **Админ меню → Рассылки → Создать рассылку**.
Отправьте текст или один медиафайл с подписью, проверьте предпросмотр и нажмите
«Отправить всем». Доступны отмена и счётчики доставки. Очередь сохраняется
при перезапуске. Неопределённые результаты отправки отмечаются «неизвестно»
без автоматического повтора. Альбомы не поддерживаются.

Пакет для Debian/Ubuntu amd64 с systemd. Внутри уже находятся исполняемый файл
бота, CLI и служба. Git, компилятор и загрузка исходников не требуются.
APT может устанавливать системные зависимости.

```bash
sudo apt install ./url_bot.deb
url-bot
```

Команда `url-bot` открывает пронумерованное меню на русском языке и при
необходимости сама запрашивает права через sudo. В SSH под root пароль sudo
не нужен. Токен при вводе отображается обычным текстом.

1. Настроить токен бота.
2. Настроить ID администратора.
3. Состояние бота.
4. Перезапустить бота.
5. Остановить бота.
6. Запустить бота.
7. Последние логи.
8. Резервная копия базы.
9. Полностью удалить бота и все его данные.
0. Выход.

После заполнения токена и ID в пунктах 1 и 2 бот запускается автоматически.
До заполнения обоих полей бот остаётся остановленным. Enter при редактировании
сохраняет прежнее значение. В дальнейшем служба запускается при загрузке системы.

Настройки: `/etc/url-bot/config.env` (root:urlbot, 0640).
База: `/var/lib/url-bot/bot.sqlite3`.
Бинарник: `/usr/lib/url-bot/bot-linux-x86_64`.
Служба: `url-bot.service`. Логи доступны через journalctl.
Токен не передаётся в аргументах команд; ввод токена виден в терминале.

Кнопки и обязательная подписка на чат/канал настраиваются в Telegram:
**Админ меню → Обязательная подписка**. Бот должен быть администратором
выбранного чата/канала. CLI предназначен для настройки и управления службой.

Обновление: `sudo apt install ./url_bot.deb` с новой версией пакета.
Конфигурация и база сохраняются при обновлении и обычном удалении.
Пункт 9 запрашивает подтверждение словом «ДА», останавливает службу и удаляет
пакет, бинарник, CLI, службу, конфигурацию, базу и служебную учётную запись.
Меню после удаления закрывается. `sudo apt purge url-bot` также удаляет
настройки и базу. Резервные копии вне каталога данных остаются.

Если раньше бот устанавливался через install.sh, сначала остановите старую
службу прежней установки, чтобы
два процесса не использовали один Telegram-токен. Этот пакет использует свою
папку данных и не переносит старую базу автоматически. При необходимости
перенесите SQLite через backup API при остановленных службах, задайте владельца
urlbot:urlbot и права 0600, затем запустите новую службу.

Исходник бота включён в `/usr/share/doc/url-bot/source/bot.py`.

Лицензия проекта — MIT. Полная инструкция по сборке находится в корневом
README проекта. Установите `requirements-build.txt` в виртуальное окружение,
затем выполните `python3 packaging/build_release.py`. Скрипт пересоберёт
бинарник, рассчитает минимальную glibc и создаст `url_bot.deb` и `SHA256SUMS`.
`python3 packaging/build_deb.py` повторяет упаковку готовой сборки и проверяет,
что исходник, версия и бинарник совпадают с манифестом.
