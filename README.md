# URL Bot

Открытый Telegram-бот для меню ссылок. Python 3.10+, SQLite, только стандартная
библиотека. Лицензия [MIT](LICENSE). Собственных внешних сервисов и
предустановленного репозитория обновлений нет; бот обращается к Telegram Bot API.

Возможности: пять ссылок с подписями RU/EN и настройкой цвета, выбор языка,
статистика по языкам, обязательная подписка, отдельные рассылки RU/EN с сохранением очереди и управление
службой через SSH. Все ссылки и тексты по умолчанию нейтральные; настройте их
в Telegram через **Админ меню**.

## Установка пакета

Debian/Ubuntu **amd64 с systemd**:

```bash
curl -fL https://github.com/Webterrorist419/url-bot/releases/latest/download/url_bot.deb -o url_bot.deb
sudo apt install ./url_bot.deb
url-bot
```

[Скачать последнюю версию url_bot.deb](https://github.com/Webterrorist419/url-bot/releases/latest/download/url_bot.deb).
Если пакет уже скачан, начните с `sudo apt install ./url_bot.deb`.

В меню задайте токен бота и Telegram ID администратора. После заполнения обоих
полей служба запустится. Управление: `url-bot`, логи:
`sudo journalctl -u url-bot.service -n 80 --no-pager`.

Конфигурация — `/etc/url-bot/config.env`, база —
`/var/lib/url-bot/bot.sqlite3`, служба — `url-bot.service`, системный
пользователь — `urlbot`. Обычное удаление сохраняет данные; `apt purge url-bot`
и пункт полного удаления в CLI удаляют конфигурацию и базу.

Подробности: [управление через SSH](packaging/README-deb.md).
Для существующей установки: [перенос данных](MIGRATION.md).

## Рассылки

**Админ меню → Рассылки → RU или EN → Создать рассылку**. Отправьте текст, фото, видео,
документ, аудио или анимацию. Форматирование текста и подписи сохраняется.
Альбомы не поддерживаются. Бот покажет предпросмотр и число получателей;
отправка начнётся только после нажатия «Отправить для RU/EN».

Получатели — сохранённые пользователи с выбранным языком рассылки, включая
администратора, если у него тот же язык. Язык интерфейса администратора не
влияет на выбор аудитории. Для RU и EN сохраняются отдельные черновики и
история; новый черновик заменяет предыдущий только для того же языка.
Сброс статистики не очищает списки получателей. Одновременно выполняется
одна рассылка; при занятой очереди другой черновик сохраняется для последующей
отправки. Список получателей фиксируется при подтверждении: новые пользователи
и последующие смены языка его не меняют.
В разделе рассылок доступны последние пять заданий, фильтр по языку,
обновление счётчиков и отмена оставшихся отправок. Уже доставленные сообщения
не удаляются.

Очередь хранится в SQLite и продолжается после перезапуска. Ошибки 403/400
учитываются как недоставленные сообщения, ограничение 429 приостанавливает
очередь на указанный Telegram срок. При сетевой ошибке или прерывании в момент
отправки результат помечается «неизвестно» и автоматически не повторяется,
чтобы снизить риск дублей. Проверить получение в этом случае нужно вручную.
Обычно скорость не превышает 10 сообщений в секунду.

Проверки рассылок: `python3 -B -m unittest -v test_broadcast`.

## Язык и статистика

После каждого `/start` бот сначала предлагает **Русский / English**. Меню и
проверка обязательной подписки открываются после выбора языка. Кнопка смены
языка также открывает явный выбор. Пользователи, ещё не выбравшие язык, не
попадают в статистику и новые рассылки.

**Админ меню → Статистика** показывает общее число уникальных пользователей
и разбивку RU/EN после последнего сброса, а также полную аудиторию рассылок
по языкам. Повторный вход не создаёт дубликатов; при смене языка пользователь
переходит в соответствующую группу. После сброса статистики он учитывается
заново при следующем выборе языка. Сохранённые языки прежних пользователей
остаются в базе до их изменения.

## Настройка кнопок

В главном меню пять ссылок. В **Админ меню → Ссылка 1–5** можно менять URL,
текст на русском и английском, цвет и включать/выключать отображение.
После сохранения или отмены ввода открываются настройки той же кнопки.

В пункте **Цвет кнопки** доступны стандартный, синий, зелёный и красный варианты.
Цвет сохраняется для каждой ссылки и применяется в обоих языках. Используются
стили `primary`, `success`, `danger` из
[Telegram Bot API](https://core.telegram.org/bots/api#inlinekeyboardbutton);
стандартный вариант оставляет оформление клиенту Telegram.

## Обязательная подписка

1. Добавьте бота администратором нужной группы, супергруппы или канала.
2. В боте откройте **Админ меню → Обязательная подписка → Чат / канал**.
3. Отправьте публичный `@username` или отрицательный числовой ID чата.
   Для закрытого канала/супергруппы это обычно `-100…`.
4. Через **Ссылка для вступления** укажите ссылку именно на этот чат:
   `https://t.me/username`, `https://t.me/+…` или `https://t.me/joinchat/…`.
5. Нажмите **Включить**. Бот проверит доступ к чату и свои права администратора.

Пользователь увидит кнопки **Подписаться** и **Проверить подписку**.
Проверка выполняется после выбора языка при `/start`, переходе в меню, смене языка и нажатии
«Проверить подписку». Участники, администраторы и владельцы получают меню;
заявка на вступление сама по себе доступ не открывает. При ошибке Telegram
доступ остаётся закрытым. Администратор бота может управлять им без подписки.

Настройки сохраняются в SQLite. После изменения чата или ссылки проверка
отключается: проверьте новую пару и включите её снова. Отключить требование
можно в том же разделе. Ввод отменяется командой `/cancel`.

Telegram позволяет открыть диалог с ботом до подписки; ограничивается выдача
меню. Ранее выданные URL и сообщения с ними Telegram не отзывает. Если ссылки
уже были распространены, эта настройка не делает их недоступными вне бота.
Для закрытых приглашений администратор должен сам проверить, что приглашение
ведёт в настроенный чат и ещё действует.

Документация проверки участников:
https://core.telegram.org/bots/api#getchatmember

## Установка

Для запуска из исходников на Linux, macOS или Windows нужен Python 3.10+:

```bash
cp config.env.example config.env
# Заполните BOT_TOKEN и ADMIN_ID в config.env.
python3 -B bot.py
```

В Windows используйте `Copy-Item config.env.example config.env` и `python -B bot.py`.
Реальный `config.env` не входит в Git и архив исходников.
Переменные окружения `BOT_TOKEN`, `ADMIN_ID`, `DATABASE_PATH` имеют приоритет
над файлом. По умолчанию SQLite хранится в `$XDG_DATA_HOME/url-bot/bot.sqlite3`
(или `~/.local/share/url-bot/bot.sqlite3`), а в Windows —
`%LOCALAPPDATA%/url-bot/bot.sqlite3`. Для прежней базы задайте `DATABASE_PATH`.

Альтернативная установка исходников как службы на Debian/Ubuntu:

```bash
sudo bash install.sh --install
```

Установщик запросит токен и Telegram ID. Команда управления:
`sudo url-bot-admin`. Эта установка использует `url-bot-source.service`,
`/opt/url-bot-source`, `/var/lib/url-bot-source` и отдельного пользователя
`urlbotsource`. Меню сохраняет установку, обновление, настройку и очистку
токена/ID, экспорт и импорт базы, полное удаление. Используйте один способ
установки для одного Telegram-токена.

Обновления из исходников используют `origin` вашего клона или явно заданный
`BOT_REPO_URL`. Адрес чужого репозитория не подставляется. Если `origin` не
настроен, задайте адрес собственного репозитория:

```bash
sudo env BOT_REPO_URL=https://github.com/OWNER/url-bot.git bash install.sh --update
```

## Сборка из исходников

Linux x86_64, Python 3.10+, `dpkg-deb` и `readelf` (пакеты `dpkg-dev`, `binutils`):

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements-build.txt
python packaging/build_release.py
```

Результат: `url_bot.deb`, `bot-linux-x86_64`, `SHA256SUMS`. Бинарник собирается
из текущего `bot.py`; `.deb` содержит CLI, службу, исходник, лицензию и сведения
о сборке. Проверка хешей не позволяет упаковать старый бинарник после изменения
исходника. Упаковка уже собранного бинарника: `python packaging/build_deb.py`.

Требование к glibc рассчитывается по всем включённым нативным библиотекам и
записывается в зависимости пакета. Сборка на новой системе может требовать
более новую glibc. Для поддержки старых систем собирайте с совместимым Python
и библиотеками. В конфигурацию пакета всегда попадают пустые токен и ID.

Архив исходников для загрузки на GitHub:
`python3 packaging/export_source.py`. Скрипт создаёт `url_bot-source.zip`
с папкой `url-bot/` и добавляет его хеш в `SHA256SUMS`.

## Проверки

```bash
python3 -B -m unittest -v test_broadcast test_bot
# На Linux после сборки:
python3 -B packaging/test_package.py -v
bash -n install.sh
```

Тесты не подключаются к Telegram. Проверки пакета распаковывают его во
временную папку и проверяют CLI, конфигурацию, контрольные суммы, бинарник
и службу без установки в систему.

## GitHub

Загрузите исходники в собственный репозиторий. `.gitignore` исключает токены,
базы, сборки, локальные пакеты и посторонний `openapi.json`.
В [`.github/workflows/ci.yml`](.github/workflows/ci.yml) настроены тесты и
сборка пакета для push и pull request. Workflow
[`release.yml`](.github/workflows/release.yml) собирает и публикует артефакты
при отправке тега, совпадающего с `VERSION`, например `v1.4.0`.
Для публикации релиза нужны разрешённые GitHub Actions и право workflow на
запись в Releases. Правила вклада: [CONTRIBUTING.md](CONTRIBUTING.md).
